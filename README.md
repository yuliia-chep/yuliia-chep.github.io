# Сайт-портфоліо Юлії Чепіжної

## Що де лежить
- `index.html` — точка входу. У ній записана версія сайту (рядок `SITE_VERSION` і `?v=...` біля файлів).
- `content.js` — УВЕСЬ текст сайту англійською (`en`) і українською (`uk`).
- `main.js` — логіка сайту
- `styles.css` — кольори, шрифти, відступи.
- `assets/` — картинки, відео, фото і CV
