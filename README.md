# Сайт-портфоліо Юлії Чепіжної

## Що де лежить
- `content.js` — УВЕСЬ текст сайту англійською (`en`) і українською (`uk`). Правиш тільки текст у лапках.
- `assets/` — картинки й відео. Щоб замінити картинку, поклади новий файл з тією самою назвою.
- `assets/photo.webp` — твоє фото (поки його немає, показується заглушка).
- `styles.css` — кольори, шрифти, відступи. Палітра на самому початку файлу.
- `main.js` — логіка сайту, чіпати не потрібно.

## Як викласти на GitHub
1. Створи репозиторій з назвою точно `yuliia-chep.github.io`, тип Public.
2. Натисни «uploading an existing file» і перетягни ВМІСТ цієї папки (index.html, content.js, styles.css, main.js, папку assets).
3. Натисни «Commit changes». За хвилину-дві сайт відкриється за адресою https://yuliia-chep.github.io

## Як щось змінити пізніше
Відкрий файл на GitHub, натисни олівець (Edit), зміни текст, натисни «Commit changes». Сайт оновиться сам.
