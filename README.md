# Сайт-портфоліо Юлії Чепіжної

## Що де лежить
- `index.html` — точка входу. У ній записана версія сайту (рядок `SITE_VERSION` і `?v=...` біля файлів).
- `content.js` — УВЕСЬ текст сайту англійською (`en`) і українською (`uk`).
- `main.js` — логіка сайту, чіпати не потрібно.
- `styles.css` — кольори, шрифти, відступи.
- `assets/` — картинки, відео, фото і CV. Щоб замінити файл, поклади новий з тією самою назвою.

## Як оновити сайт на GitHub (без помилок)
Завжди завантажуй УСІ файли разом, а не окремі:
1. Розпакуй архів.
2. У репозиторії yuliia-chep.github.io натисни Add file → Upload files.
3. Виділи ВМІСТ розпакованої папки (index.html, content.js, main.js, styles.css, README.md і папку assets) і перетягни у вікно браузера. Робити це краще в Chrome.
4. Дочекайся, поки завантажаться всі файли, і натисни Commit changes.
5. Зачекай 1–3 хвилини. GitHub Pages віддає файли з кешем до 10 хвилин, тому відкрий сайт через Cmd+Shift+R (жорстке оновлення) або в анонімному вікні.

## Як перевірити, що оновилось
Відкрий https://yuliia-chep.github.io, натисни правою кнопкою → View page source: у рядку `<meta name="build" ...>` має бути номер версії з назви архіву. Той самий номер видно в консолі браузера (Cmd+Option+J) як "Portfolio build ...".

## Дрібні правки
Текст: відкрий content.js на GitHub, натисни олівець (Edit), зміни текст у лапках, Commit changes.
Картинка: Add file → Upload files у папці assets, файл з тією самою назвою замінить старий.
